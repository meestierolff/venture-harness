# reports/

Generated analysis output, committed so decisions stay traceable.

| Directory      | Written by                          | Cadence              |
| -------------- | ----------------------------------- | -------------------- |
| `weekly/`      | `pnpm weekly` + $weekly-learning    | weekly               |
| `quality/`     | $quality-gate (substantial changes) | per change           |
| `seo/`         | $seo-aeo-engine                     | weekly / on analysis |
| `analytics/`   | $experiment-analytics-engine        | on analysis          |
| `experiments/` | $experiment-analytics-engine        | per decision         |

Reports cite their data sources and state their limitations. A report
without limitations is incomplete by definition.
