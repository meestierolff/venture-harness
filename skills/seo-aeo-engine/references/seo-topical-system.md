# SEO topical system

Use this playbook for topical wedges, query clusters, canonical ownership,
emerging queries, content decisions, consolidation, and search recovery.

## Repository profile

Maintain venture, domain, market, languages, audience, conversions, business
type, local relevance, maturity, confirmed/candidate/excluded wedges, discovery
status, experts, evidence sources, and last review date. Allowed maturity values
are `pre-launch`, `new-domain`, `early-signal`, `growing`, `established`, and
`recovery`.

## Wedges and clusters

A topical wedge needs product relevance, meaningful demand and decisions,
adjacent distinct clusters, credible expertise/original value, a conversion
relationship, defensibility, and maintainability. Start with one primary and at
most one secondary wedge.

A cluster represents one user task across close wording variants. Record its
representative query, variants, intent, funnel stage, locale, audience, owner,
page type, evidence, conversion, links, and state. Ownership states are
`owned`, `candidate`, `planned`, `expand-existing`, `merge`, `redirect`,
`no-index`, `rejected`, and `retired`.

Prefer: protect winner → improve owner → add section/evidence → strengthen
links → consolidate overlap → create a distinct page. A cluster may have no
page when relevance, expertise, truth, differentiation, demand, or maintenance
does not justify one.

## Evidence analysis

Compare equivalent windows and segment brand/non-brand, device, country,
locale, and search type when material. Detect:

- emerging clusters from sustained/new visibility, positions 4–20, qualified
  conversion, related variants, grounding activity, or unintended owners;
- CTR opportunities relative to position, intent, brand, device, country,
  page type, history, nearby queries, and conversion quality—never one global
  benchmark;
- cannibalization only when the same task is materially split or ownership
  oscillates, not when distinct intents both appear;
- release, campaign, seasonality, attribution, sample, and zero-vs-missing
  explanations before assigning cause.

Classify emerging work as ignore, monitor, expand existing, improve metadata,
add links, compare, create owner, or product-truth review.

## Content gate

Create an indexable owner only when the task is distinct, belongs to an
approved/candidate wedge, has no adequate owner, can be answered truthfully,
adds original value, has an appropriate next step and internal-link plan, and
can be maintained. Answer near the start; use descriptive headings; distinguish
fact, estimate, opinion, and hypothesis; name entities, dates, currencies,
units, and limitations. No minimum word count.

Every material page needs a real contribution: experience, sourced data,
analysis, worked example, method, expert judgment, comparison framework,
verified current facts, tool, or product-specific insight. Assign the human
expert needed to review accuracy, nuance, originality, truth, and safety.

## Bounded action

Protect winners. By default take any P0 discovery repair and no more than three
high-confidence content actions in one cycle. Do not retain a page because work
was spent on it, and do not remove a winner from one short window.
