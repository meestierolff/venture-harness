## Goal

Recover and preserve the prior implementation, independently verify every
claim, and complete every implementable P0, P1, and P2 requirement in the
founder's v0.2 Core and Winner Loop completion brief. The result must be a real
pnpm workspace whose Core packages, venture materialization, recursive runtime,
Agent Surfaces, durable graphs and loops, fleet upgrades, Winner Loop, security
checks, fixtures, and public documentation agree with executed behavior.

## Scope and authorization

Repository inspection, local implementation, deterministic fixtures, tests,
commits, branch push, and a draft pull request are authorized. GitHub branch and
draft-PR writes are allowed only after local verification and require read-back.

The run may not deploy a real customer venture, publish social content, create
advertising spend, send customer communications, charge a customer, mutate or
delete production provider resources, publish a package/release, or merge a
pull request. Missing provider credentials leave a complete adapter and a
precise live-verification gap; they do not justify an implementation stub.

## Completion criteria

The founder brief's Definition of Done and required artifacts are authoritative.
In addition, `pnpm verify`, `vh verify release`, packed CLI/MCP/SDK checks, all
four golden paths, all negative controls, secret/history/package scans, and
generated parity must pass. A skipped live check is not a pass and must identify
the missing credential/account/review, exact command, and expected evidence.

## Stop conditions

Stop only for a genuine external prerequisite after all reversible local work
and deterministic fixtures are complete, or for an unauthorized destructive or
production effect. Scope size, test failures, missing provider credentials, and
repair complexity are not stop conditions.
