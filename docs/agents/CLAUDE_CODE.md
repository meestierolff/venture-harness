# Claude Code adapter guide

## Instruction source

[CLAUDE.md](../../CLAUDE.md) begins with `@AGENTS.md`, importing the
canonical constitution, then adds only Claude-specific notes.

## Skills

Claude-ready copies live in `.claude/skills/<name>/`, generated by
`pnpm agents:sync` from `skills/<name>/`. Invoke as slash commands
(`/offer-architect`) or by name. Codex metadata (`agents/openai.yaml`) is
excluded from Claude copies.

Never edit `.claude/skills/` directly. Edit `skills/`, run
`pnpm agents:sync`, and check with `pnpm agents:check`.

## Subagents

Eight bounded subagents live in [.claude/agents/](../../.claude/agents/):
market-researcher, offer-critic, evidence-verifier, product-truth-auditor,
visual-reviewer, seo-auditor, experiment-analyst, security-reviewer. Each
has one responsibility and no permission to send, publish, charge, deploy,
or merge.

## Hooks

Optional safe hooks live in [.claude/hooks/](../../.claude/hooks/), documented
in [.claude/README.md](../../.claude/README.md). None are destructive, none
call paid services, none are enabled by default (`settings.json` is not
committed).

## Working style

- Plan mode before broad changes.
- Subagents for bounded research/review; keep main context focused.
- `pnpm verify` before reporting completion.
- `/context` when instruction loading is unclear.
