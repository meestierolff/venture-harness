## Purpose

The claims ceiling for this template and every child venture. A local test can
support `PROTOTYPE`; `LIVE` requires production read-back evidence. Public
venture claims must add their own rows and match the allowed wording.

## Statuses

| Status       | Meaning                                                  | Public rule                         |
| ------------ | -------------------------------------------------------- | ----------------------------------- |
| LIVE         | Works in production and was read back                    | present tense within verified scope |
| CONCIERGE    | Humans deliver it                                        | disclose human delivery             |
| PROTOTYPE    | Works only in local, fixture, sandbox or demo conditions | label prototype/demo/test           |
| PLANNED      | Not built or not connected                               | future tense only                   |
| UNDER REVIEW | Evidence is being checked                                | do not publish                      |
| UNVERIFIED   | No acceptable evidence                                   | do not publish                      |
