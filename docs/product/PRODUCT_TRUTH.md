- Status: FOUNDER ALPHA REGISTER — local/fixture evidence only; no live child venture
- Owner: harness maintainers
- Last updated: 2026-08-09

## Purpose

The claims ceiling for this template and every child venture. A local test can
support `PROTOTYPE`; `LIVE` requires production read-back evidence. Public
venture claims must add their own rows and match the allowed wording.

## Statuses

| Status       | Meaning                                                  | Public rule                         |
| ------------ | -------------------------------------------------------- | ----------------------------------- |
| LIVE         | Works in production and was read back                    | present tense within verified scope |
| CONCIERGE    | Humans deliver it                                        | disclose human delivery             |
| PROTOTYPE    | Works only in local, fixture, sandbox or demo conditions | label prototype/demo/test           |
| PLANNED      | Not built or not connected                               | future tense only                   |
| UNDER REVIEW | Evidence is being checked                                | do not publish                      |
| UNVERIFIED   | No acceptable evidence                                   | do not publish                      |

## Surfaces inspected

README, founder quickstart, synthetic Golden Path, public release documents,
homepage, pricing, root/page metadata and structured data were inspected and
aligned to visible alpha/prototype/fixture wording. The Stack example contains
references and placeholder metadata only. The sample interface is labeled
illustrative. A child venture must repeat the audit for its own emails,
onboarding, store metadata, screenshots, consent copy and every public surface.

## Evidence

Only the paths in the register are evidence. The 2026-08-09 full Golden Path
verification belongs to a prior source state. On the current final tree, its
product/runtime slices pass; the root slice reached the standalone child server
check before this local sandbox denied loopback listening with `EPERM`, so a
socket-capable CI refresh remains pending. Fixtures are synthetic and no row
asserts a live provider, production deployment, TestFlight build, user, sale,
email delivery, search result or learning outcome.
