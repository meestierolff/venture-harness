# Anti-slop checklist

Applied at step 18 of the design-director process. Every item is answered
PASS, or FAIL with the fix taken. "Justified exception" requires the
founder's sign-off recorded in docs/brand/DESIGN.md.

## Template smells

- [ ] No generic purple AI gradient (or any trend-default gradient used
      without a thesis reason).
- [ ] No glowing AI orbs.
- [ ] No glassmorphism without a functional reason.
- [ ] No six identical feature cards; features are weighted by importance.
- [ ] No bento grid unless the content genuinely has grid semantics.
- [ ] No floating cards without purpose.
- [ ] No generic stock illustrations (people-at-laptops, abstract blobs).
- [ ] Layout is not recognisably a copied Framer/template composition.

## Identity smells

- [ ] Logo direction is not a standard icon beside a wordmark presented
      as bespoke.
- [ ] Colour system would look wrong on a competitor's site.
- [ ] Typography pairing was chosen for this ICP, not defaulted.
- [ ] There is one signature moment a visitor could describe later.

## Composition smells

- [ ] Mobile is re-composed, not desktop stacked.
- [ ] Every section earns its viewport (no filler sections).
- [ ] Hierarchy survives squinting: one primary action per screen.

## Copy smells

- [ ] Hero copy could NOT be pasted onto a competitor's site unchanged.
- [ ] No banned phrases (config/content.yaml).
- [ ] Claims map to PRODUCT_TRUTH.md ids.

## Honesty

- [ ] Sample data labeled. Illustrative interfaces labeled. Prototype and
      concierge disclosures present where required.
