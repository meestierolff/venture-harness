# Synthetic launch fixtures

Everything under this directory is synthetic. It proves routing, graph
compilation, interruption/resume, idempotency, redaction, failure isolation,
and report generation against local/mocked transports. It is not evidence of a
real venture, provider resource, user, purchase, deployment, or App Store state.

- `web-saas`: thin MVP, Next.js, Neon, Stripe test mode, Brevo, Vercel,
  GA4/GSC/Bing plans, consolidated manual MijnDomein DNS, discovery baseline,
  and weekly learning.
- `ios-subscription`: product-first hybrid rail, Expo, RevenueCat Test Store,
  explicit first-app-record manual node, EAS/TestFlight continuation, ASO, and
  App Store analytics plan.
