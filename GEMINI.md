# Gemini CLI adapter

This file is intentionally thin. The canonical rules live in repository
documents, not here.

Before substantial work:

1. Read `AGENTS.md` — it is the repository constitution and navigation map.
2. Read `PROJECT.md` — current venture state.
3. Read the active plan under `docs/plans/active/`.
4. Read the relevant canonical skill in `skills/<name>/SKILL.md`.

While working:

5. Treat project documents (`docs/`, `config/`) as sources of truth.
6. Respect `docs/product/PRODUCT_TRUTH.md` — public claims must trace to it.
7. Use the deterministic scripts in `scripts/` (see `package.json`) instead
   of re-deriving transformations, validation, or aggregation.
8. Run `pnpm verify` before reporting completion.
9. Do not deploy, publish, send, charge, or merge without human approval.

Adapter notes for Gemini CLI are in `docs/agents/GEMINI.md`.
